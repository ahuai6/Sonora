# Sonora 1.2.3

新下载的歌曲仅保存一个音频文件。曲名、歌手、专辑等标签、封面及可获取的歌词直接写入音频，不再自动生成外部歌词文件或翻译文件。

## 歌词与翻译

- 默认开启“下载时内嵌歌词”，沿用旧配置的 `autoLyrics` 值；歌词会在提交音频前与元数据一起写入并回读验证。
- “合并翻译歌词”沿用 `saveTranslation` 值，原文与翻译按相同时间戳合并到同一歌词标签；关闭后仅内嵌原文。
- 沿用现有歌词格式和来源设置，支持自动模式、逐行 LRC、逐字增强 LRC、TTML 文本。自动模式优先真实逐字时间。
- 内嵌歌词与自动匹配标签独立控制：关闭元数据匹配仍可内嵌歌词，关闭内嵌歌词仍可自动写入标签和封面。
- 未取得歌词时保留文件已有的内嵌歌词；接口失败或格式不支持时提示原因，不生成外部文件作为回退。

此前已有的外部歌词文件保持不变。单独的歌词搜索和用户主动导出功能不受影响。

## 验证

- 81 项核心测试通过，覆盖六种音频格式的内嵌歌词、逐字时间与翻译、标签 / 封面回读、音频数据保留、独立开关、LRC / TTML 格式和失败保留音频。
- 29 项 Electron 流程检查通过，实际确认下载后的歌词包含逐字时间及双语内容，下载子目录只存在音频文件。
- 使用独立测试目录，不修改用户已有音乐或外部歌词文件。

运行新版前请退出旧版 Sonora，配置目录继续沿用。
