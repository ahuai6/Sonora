# Sonora 1.3.0

本版完成 1.2.3 审查清单中的依赖、安全、逻辑及界面修复，保持下载仅生成音频文件，标签、封面与可取得的歌词直接内嵌。

## 依赖与上游

- 对照 npm 官方稳定版本及上游正式发布核对所有直接依赖，改用精确版本。music-metadata 更新至 12.3.2，electron-builder 更新至 26.18.1。
- Electron 45.1.0、React 19.3.1、TypeScript 7.0.2、Vite 8.3.5、Playwright 1.64.1，以及网易云 4.41.1、QQ 2.6.0、酷狗 1.6.3 等保持已核对的稳定版本。
- Node 类型使用 24.19.2，对齐 Electron 内置 Node 24.22.1。使用 Node 24 与 npm 11；已使用 npm 11.21.1 完成干净安装验证。
- 覆盖 basic-ftp 为 6.2.3、taglib 使用的 uuid 为 14.0.3；删除酷狗 vendor 中本应用不使用的旧开发打包工具依赖，保留 API 源码及许可证。全量与生产依赖审计均为 0 个已知漏洞。
- 已核对固定的酷狗与 LRC-GET 上游版本；详见 vendor/SONORA-PATCHES.md。未把所有间接依赖强行升级到不兼容的主版本。上游仍可能输出弃用提示，这与已知漏洞计数不同。

## 行为修复

- 本地内嵌增强 LRC 保留逐字时间，同一时间戳的原文和翻译合并显示；本地 TTML 同样进入统一歌词模型。
- 歌词写入校验容忍容器对 CRLF 和末尾空白的标准化，修复手动歌词在部分格式中保存失败；保存未成功时保留此前的恢复点。
- 扫描期间移除的音乐不会被旧快照重新加入；已经存在的收藏变化不会被覆盖。
- 下载进入最终“保存文件”阶段后暂时禁止暂停、取消和移除，避免任务显示已取消但文件已经完成保存。
- 配置保存时验证必需路由。启动遇到无效配置时回退上次有效配置或默认配置，保留原配置并显示提示。
- 取消下载会传递到取链、元数据、歌词、HTTP 请求及可取消的 SDK 工作线程；不再在取消后继续尝试备用取链源。
- JSON / 文本响应在读取过程中按字节限制；切换页面后丢弃过时搜索结果；按钮及弹窗内的空格保留原生交互。

## 界面

提升浅色辅助文字对比度与列表字号；增加紧凑 / 舒适密度；本地文件次要操作放入“更多”菜单。标签弹窗保持底部操作可见，支持焦点约束、Esc 关闭和退出后恢复焦点，提示避开保存及关闭按钮。

## 验证

先更新依赖并运行原有测试（81 项核心、29 项桌面检查及构建通过），再修复审查问题并增加回归覆盖。最终 95 项核心测试、36 项桌面流程检查及生产构建通过；Windows 打包回归包含 ASAR 内 SDK 工作线程验证。详情见 [逐项验证](1.3.0-审查修复验证.md)。

真实个人账号、会员权益与所有公共节点在不同地域的可用性未逐一实测。本版回归使用隔离配置和本地生成的音频，不修改使用者已有音乐。GitHub CI 已配置，提交后不持续追踪云端构建状态。
