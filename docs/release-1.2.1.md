# Sonora 1.2.1

修复本地标签匹配只填入曲名、歌手、专辑，以及保存标签 / 内嵌歌词时 Windows 文件占用导致的 EPERM 替换失败。

## 标签匹配

- “采用标签”继续查询歌曲、专辑详情及可用创作者信息，支持年份、流派、曲序、总曲数、碟序、总碟数、作曲、ISRC、专辑歌手。
- 网易云、QQ、酷狗和 MusicBrainz 使用各自的详情适配，详情路由和字段路径可以替换。
- 源站没有返回的字段会明确提示，保留已有本地值，可手动补充或选择其他来源。数字流派 ID 不会伪装成流派名称。
- 实测网易云《夜に駆ける》返回年份 2019、作曲 Ayase、曲序 / 总曲数 / 碟序 / 总碟数均为 1；该候选未返回流派和 ISRC。

## 文件保存

- 保存前暂停当前本地歌曲并释放本应用的音频读取流，写入期间禁止创建该文件的新读取流。
- 临时 EPERM / EACCES / EBUSY 占用会有界重试；持续占用或权限不足时保留原文件和当前编辑内容，并显示可读提示。
- 新增“另存为副本”，保存同格式的新文件并加入本地音乐库，不覆盖已有文件。
- 保存失败也会重新载入播放器文件来源，可继续播放或重试。
- 原有的副本写入、回读验证、原文件备份和恢复机制继续生效，不重新编码音频。

## 验证

- 57 项核心测试通过，包含六种音频格式的标签 / 封面 / 歌词写入和音频有效载荷不变检查。
- 26 项 Windows Electron 流程检查通过，实际验证扩展字段采用并写回、正在播放时保存、持续 Windows 文件锁导致保存失败、输入保留和另存副本。
- 临时 Windows 外部读取句柄解除后，保存重试成功；持续文件锁时未修改原文件。
- 33,419,167 字节、261 秒 FLAC 的独立测试副本验证通过：活跃读取流关闭、网易云实测扩展标签和歌词 / 封面写入、压缩音频有效载荷不变、备份恢复后文件逐字节相同。用户原文件哈希未变。

运行新版前请退出旧版 Sonora。用户配置继续使用原有用户数据目录。
