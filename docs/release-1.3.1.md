# Sonora 1.3.1

## 本地音乐

- 勾选歌曲后，可播放所选、批量移除音乐库记录或移入 Windows 回收站。
- “移除所选记录”只改音乐库，保留磁盘文件；“所选移入回收站”统一确认后移动音频文件，关联的外部歌词保留。
- 新增“刷新”，进入页面时也刷新一次。重新核对已导入文件，清理不存在的记录，读取已变更的标签和封面；权限 / 暂时读取错误保留记录并提示。刷新不会自动扫描新文件，新增歌曲仍使用“导入音乐”或“扫描文件夹”。

## 下载中心

- 新增勾选、当前列表全选，批量暂停、重试、取消下载、移除记录及回收站操作。筛选变化时清空选择，批量操作只处理当前列表所选项。
- 新增“刷新”和“文件已丢失”筛选。文件被外部删除后，对应记录不再显示已完成，可重试或移除；文件恢复到原路径后刷新会重新识别。
- 移除运行中的任务会先取消并等候清理，避免后台任务继续或留下临时文件。正在最终提交的任务暂不可操作，会显示跳过数量。
- 回收站操作仅处理已落盘且不在运行中的文件，统一确认；成功后清理对应音乐库记录。失败条目保留，并显示原因。

批量工具栏适配小窗口，提示移至播放器上方，避免遮挡刷新按钮。所有文件操作只针对用户选择的已有记录，不新增永久删除功能。

## 针对性验证

- 11 项新增核心测试：外部删除与恢复、元数据更新、收藏保留、权限错误、记录移除保留文件、取消回收站确认、批量文件回收、部分失败、提交边界、批量状态操作、真实下载流取消与临时文件清理、刷新和移除竞态、输入校验。
- 另运行原有 B04 / B05 两项相关竞态回归。
- 12 项桌面检查：多选操作、保留文件、取消 / 确认回收站、手动刷新、页面进入刷新、丢失筛选、重试入口、记录移除、跨列表同步、空列表刷新和小窗口布局，无渲染错误。
- TypeScript 检查与生产构建通过，打包程序运行上述针对性桌面流程。

仅使用隔离的测试配置和生成音频，桌面回收站操作替换为移动到测试目录；未触碰使用者原有音乐。本次依用户要求未重跑全量回归。
