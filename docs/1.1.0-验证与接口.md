# 1.1.0 验证与接口记录

日期：2026-10-29。公开接口的结果只代表本次请求，运行时仍可能变化。

## 歌词

| 来源 | 实现 | 实测 |
|---|---|---|
| 网易云 | 内置增强 API 的 `lyric_new`，`/lyric/new` 返回 YRC 与 `ytlrc` | 样本 45 行、存在逐字时间，30 行翻译完成对齐 |
| QQ | 官方 `music.musichallSong.PlayLyricInfo/GetPlayLyricInfo`，数值 songID | 样本 63 行、602 个逐字片段；旧普通歌词接口被拒绝时仍可获取 QRC |
| 酷狗 | `search_lyric` + `lyric(fmt=krc,decode=true)` | 样本 40 行，存在逐字时间；相对词时间转换成绝对时间 |
| AMLL TTML DB | 按网易云 / QQ ID 请求社区库，可在设置里选择 | 样本 63 行、43 行翻译；XML 解析与导出往返测试通过；未收录时自动模式保留平台结果 |

原文与翻译按时间匹配（最大 1200 毫秒容差，每条翻译最多使用一次），合并输出时复用原文时间戳。未匹配的翻译不会强行附在其他歌词行上。没有真实逐字时间时，自动模式降级逐行；手动逐字模式明确报错。增强 LRC 使用 `.lrc`，TTML 使用 `.ttml`，不会把 KRC 解码文本伪装为 LRC 或二进制 KRC。

主要实现位置：`main/services/lyrics.mjs`（格式解析 / 对齐 / 导出）、`main/providers/registry.mjs`（取词与来源回退）、`profiles/providers.json`（可替换路由）。QRC 解码使用 MIT 的 [LRC-GET](https://github.com/valenbine/LRC-GET/tree/2cc0e67dcfc567a122ebb953ef696783a6760d17)，许可证随源码保留。社区词库为 [AMLL TTML DB](https://github.com/amll-dev/amll-ttml-db)，运行时请求，不在应用中打包歌词。

## 酷狗登录

复现错误：二维码生成成功，但轮询 SDK 抛出 `{status:502,body:{data:"参数错误,请检查参数:20006",status:0,error_code:20006}}`。检查其轮询模块发现 `dev` 来自 `cookie.KUGOU_API_DEV`；旧设备数据缺少此字段。

补充稳定设备名称后，上游返回 `{data:{status:1},status:1,error_code:0}`，即等待扫码。旧数据会自动补齐字段。IPC / SDK 错误统一转成文字，避免 `[object Object]`。此验证未使用真实个人账号扫码，不能将“等待扫码”当作实际账号授权成功。

## 无用户账号凭据的音源

| 服务 | 结果 | 处理 |
|---|---|---|
| [Injahow Meting](https://github.com/injahow/meting-api) | 网易云样本返回音频 URL，Range 206，音频签名有效 | 保留，可手动选择 |
| [铭心音乐](https://api.mxin.me/) | 网易云样本返回音频 URL，Range 206，音频签名有效 | 保留，可手动选择 |
| [Sakurink Meting](https://apivc-meting.sakurink.eu.org/registration/) | 网易云样本返回音频 URL，Range 206，音频签名有效 | 保留，可手动选择 |
| [Meting imlam](https://meting.imlam.com/) | 新候选 URL 请求 HTTP 403 | 不加入默认配置 |
| [JerryMusicAPI](https://music-api.jerrynis.com/) | 新候选 URL 请求超时 | 不加入默认配置 |
| 其他 Meting 节点 `meting.qjqq.cn` | HTTP 522 | 不加入默认配置 |

“无需账号”表示调用时不要求 Sonora 用户提供个人 Cookie，不表示覆盖全部付费曲目，也不能说明公共服务端的上游身份。QQ / 酷狗全曲库匿名下载未获得可靠保证。默认保留已有服务，不新增本次未验证成功的节点。名称检索型慕名 QQ 仍默认关闭，可自行启用，严格核对歌名和歌手。
