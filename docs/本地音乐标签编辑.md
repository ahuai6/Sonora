# 本地音乐标签编辑

在“本地音乐”每首歌右侧点击“编辑标签”按钮，打开编辑器。标签修改会写入实际音频文件，封面显示在列表、播放器和编辑器中。

从 1.2.2 起，新下载歌曲默认先按原平台歌曲 ID 获取元数据和封面，写入后再加入音乐库；可在“偏好与音源”关闭“自动匹配并写入标签”。此前下载或手动导入的歌曲可继续使用编辑器匹配，不自动批量修改。见 [1.2.2 更新说明](release-1.2.2.md)。

从 1.2.3 起，下载时获取的歌词也直接内嵌到音频。开启“合并翻译歌词”会将翻译与原文按相同时间戳写入同一标签，不再自动生成旁置歌词文件或翻译文件。可通过“下载时内嵌歌词”开关控制，独立于元数据匹配开关。单独的歌词搜索和手动导出功能仍可使用。

从 1.3.0 起，本地读取保留增强 LRC 的逐字时间与同时间戳翻译，播放面板按词高亮。手动保存允许音频容器统一末尾换行；保存失败不改变此前的恢复点。编辑器正文独立滚动，保存和取消固定可见。列表的文件位置、移除记录及回收站操作收纳到“更多”菜单。

## 手动编辑

支持曲名、歌手、专辑、专辑歌手、年份、流派、曲序 / 总曲数、碟序 / 总碟数、作曲、ISRC 和备注。多个歌手、作曲或流派使用英文分号分隔。

封面可从本机选择 JPEG、PNG、WebP 或 GIF，也可以填写图片 URL，或采用在线候选的专辑封面。载入图片后会预览；选择或移除封面，点击“保存到文件”后才修改音频。写入封面统一使用 JPEG / PNG，较大图片缩小至最长边 1600 像素。

## 在线匹配

支持网易云、QQ 音乐、酷狗、MusicBrainz 和 LRCLIB（歌词）。聚合搜索包含前三个平台和 MusicBrainz；LRCLIB 可单独选择。

结果会显示曲名、歌手、专辑、来源、时长，以及与本地文件的时长差。采用某条结果前请核对录音版本。可以分别点击“采用标签”“采用封面”“获取歌词”，允许从不同结果选取不同内容。空白候选字段不会清除已有信息。

从 1.2.1 开始，“采用标签”会继续请求歌曲、专辑详情和可用的创作者信息，填入年份、流派、曲序 / 总曲数、碟序 / 总碟数、作曲、ISRC、专辑歌手。网易云还会从原始歌词的明确“作曲”署名提取作曲者。数据源未提供的字段会在编辑器内提示，并保留本地原值；不会用猜测值代替。未知数字不作为流派名称写入。

平台详情路由位于 `routes.metadataDetail` / `metadataAlbum` / `metadataCredits`，同现有路由一样可以替换；自定义响应可用路由的 `metadataPaths` 将标签字段映射为 JSON 路径。旧的用户配置未包含这些路由时，采用新版内置路由作为补充。

MusicBrainz 按发行版本列出专辑，可补充年份、ISRC、MusicBrainz ID 等；其封面来自 Cover Art Archive。MusicBrainz 不提供歌词。网易云、QQ、酷狗使用现有可替换平台引擎；可能受到账号或网络条件影响。公开元数据库地址配置在 `profiles/providers.json` 的 `metadataSources`，可以在高级 JSON 中替换。MusicBrainz 请求按至少 1.1 秒间隔串行发送，公共元数据库不接收个人平台 Cookie。

## 内嵌歌词

先在“内嵌歌词”页选择获取格式和是否合并翻译，再回“在线匹配”选择所需平台结果并“获取歌词”。可以加载逐行 LRC、逐字增强 LRC、TTML 或纯文本，再直接修改文字。

勾选“将此歌词写入音频”后保存，才会修改文件的歌词文本标签；不勾选会保留原有内嵌歌词。“清除内嵌歌词”会将待写入内容设为空，需要保存才生效。播放器对 LRC、逐字 LRC 或 TTML 文本标签的支持不同；本应用可读取内嵌文本，播放面板也会转换已识别的时间格式。

内嵌歌词优先于同名 `.lrc` 文件；没有内嵌歌词时仍读取原有旁置歌词。此功能不会自动删除旁置歌词。

## 文件保护与恢复

- 先复制到音频同目录的临时文件，在副本写标签并重新读取验证；编码、声道和时长验证通过后才替换原文件，不转码。
- 每次保存前在用户数据目录 `tag-backups` 中保留原文件完整副本。编辑器的“恢复上次备份”可撤回最近一次保存；恢复操作也保留恢复前的文件。
- 备份包含完整音频，会占用额外磁盘空间。不会自动删除这些备份。
- 打开编辑器后如果文件被其他程序修改，会拒绝保存，要求重新打开编辑器。写入失败会清理临时文件；只修改已导入音乐库中、由用户明确选择的文件。
- 若正在播放同一首本地歌曲，保存前暂停，关闭本应用的音频读取流，并在写入期间阻止新读取。对短暂的 Windows 共享占用有限重试；保存后或失败后重新载入播放器来源，可重新点击播放。
- 持续遇到 EPERM / EACCES / EBUSY 时，原文件保持不变，编辑器保留输入。可关闭其他播放器后重试，或选择“另存为副本”，在指定位置保存同格式的新文件并加入音乐库。副本不覆盖已存在的文件。

已在自行生成的 MP3、FLAC、M4A、OGG、Opus 和 WAV 样本验证标签 / 封面 / 歌词写入，并逐格式比较音频有效载荷不变、备份可恢复。其他可读格式由底层标签库判断是否可安全写入，不支持时显示原因。
