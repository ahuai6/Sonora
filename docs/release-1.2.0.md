# Sonora 1.2.0

- 本地音乐标签编辑器：曲名、歌手、专辑、专辑歌手、年份、流派、曲序 / 碟序、作曲、ISRC 和备注。
- 封面：读取并展示内嵌封面，支持本机图片、网络图片、在线匹配封面；保存后写入音频文件。
- 在线匹配：网易云、QQ、酷狗、MusicBrainz / Cover Art Archive；候选由用户核对后分别采用。
- 内嵌歌词：选择平台或 LRCLIB 歌词，支持手动编辑、逐行 / 逐字 LRC、TTML 文本和同时间戳翻译。
- 文件保护：临时副本验证后替换、原文件备份与恢复、并发写入和外部修改冲突检查。
- 加入用户网络验证过的 JerryMusicAPI 网易云备用取链配置。

验证：六种格式的标签、封面、歌词读写与音频有效载荷一致性验证通过；桌面流程覆盖实际写入、公开元数据库候选、歌词获取与修改、封面显示和重读。

用法：本地音乐 → 歌曲右侧“编辑标签” → 选择信息 / 封面 / 歌词 → 保存到文件。备份位于用户数据目录 `tag-backups`，占用完整音频副本的空间。

仅供学习使用，请于下载后24小时自行删除。应用不会自动删除文件。
