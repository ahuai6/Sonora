## Sonora 1.1.0

- 歌词：对接网易云 `/lyric/new`（YRC）、QQ 官方 QRC 和酷狗 KRC，转换真实逐字时间；支持逐行 LRC、逐字增强 LRC、TTML 导出。
- 双语：原文和翻译写入同一文件，使用完全一致的行时间戳；自动下载旁置歌词也使用所选格式。
- 歌词来源：增加 AMLL TTML 社区库作为可选补充来源，按平台歌曲 ID 匹配，不按相似歌名替换。
- 酷狗登录：修复设备参数缺失引起的 20006 错误，将 SDK 对象错误转换为可读提示，完善等待确认状态。
- 音源：增加“自动 / 仅内置 / 指定公共备用服务”切换；指定服务失败会直接报错，不悄悄改用其他服务。公共服务不接收用户登录 Cookie。
- 工程：版本化文件名、Windows Actions 构建与 Release 附件上传、歌词解析与回归测试。

验证：37 项核心测试、18 项桌面流程检查通过；三平台逐字歌词和酷狗二维码等待扫码状态实测通过。未代替用户完成真实账号扫码确认。Injahow、铭心、Sakurink 的网易云样本验证为可读取音频；不保证全部歌曲、平台或会员音质可用。

Windows x64 免安装 EXE 与 SHA256 由 GitHub Actions 构建成功后上传到此 Release；源码可直接下载下方 GitHub 自动生成的压缩包。未对第三方接口作永久可用承诺。
