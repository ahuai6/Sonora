# Sonora 1.3.3

修复“我的歌单”首屏一直加载的问题。此前点击入口时先生成请求编号，随后页面切换又递增编号，因此正常返回的数据及结束加载动作都被当成过期请求忽略。现在先完成页面切换，再建立当前请求编号。

- 网易云、QQ、酷狗的个人歌单共用此界面路径，均使用修正后的加载状态处理。
- 当前请求成功、失败、返回空列表或缺少用户 ID 时都会结束加载；具体接口错误在页面说明中展示。
- 返回或切换页面后，旧请求的成功结果和错误均不会覆盖新页面。
- 加载更多失败保留此前的列表；页码仅在成功后提交，重试不会跳过失败的一页。
- 已失效账号的切换错误显示提示，避免未捕获异常。

## 针对性验证

先使用成功返回歌单的本地接口复现旧版持续加载，再修复并验证。12 项桌面检查通过，覆盖三平台首屏、40 条后分页追加、分页失败后重试同一页、空结果、HTTP 错误、返回重开、迟到的成功 / 错误响应、缺少用户 ID、账号失效；无渲染异常。TypeScript 检查和生产构建通过，打包版运行相同流程。

验证只使用隔离的账号夹具和本地 HTTP，没有读取或操作使用者的个人账号。本次本地仅进行这些相关检查，未重跑全量回归。
