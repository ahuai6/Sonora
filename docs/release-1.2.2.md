# Sonora 1.2.2

新下载的歌曲会自动匹配并写入元数据和封面，无需首次打开标签编辑器后手动匹配。

## 使用

下载后依次执行音频校验、匹配标签、保存并加入本地音乐库。自动匹配默认开启，旧版配置也会获得默认值；可在“偏好与音源”关闭“自动匹配并写入标签”，对后续下载生效。本次功能不批量改写此前已下载或导入的歌曲。

自动匹配直接使用网易云、QQ、酷狗的原始歌曲 ID 获取详情和专辑信息，不会自动采用同名搜索结果或其他发行版本。支持曲名、歌手、专辑、专辑歌手、年份、流派、曲序 / 总曲数、碟序 / 总碟数、作曲、ISRC 和下载候选封面；源站缺失字段保留音频已有值。仍可在本地音乐中继续手动修改。

## 失败处理和文件保护

- 元数据与封面请求最多等待 20 秒；超时或接口失败时使用下载信息中的曲名、歌手、专辑，并在结果中提示。
- 标签写入失败或格式不支持时保留原始下载音频，任务仍完成，可稍后从本地音乐重试。
- 下载阶段在同目录的独立临时副本写入、回读验证并核对音频格式 / 声道 / 时长，再提交最终文件。不转码，不为新下载额外生成完整音频备份。
- 自动处理可在提交最终文件前暂停或取消，清理本次临时文件；已提交的文件会完成整理。
- 已有内嵌歌词和其他未修改标签保留。“同时保存歌词”仍控制原有旁置歌词下载。

## 验证

- 76 项核心测试通过：六种音频格式的自动标签和封面写入、源平台 ID 对接、接口失败与超时、禁用开关、写入失败保留原音频、取消与重试、原有标签和歌词保留，以及中断后的临时文件清理和已保存音频保护。
- 28 项 Electron 桌面流程检查通过，包含下载后直接读取全部扩展字段与封面、音频有效载荷不变，以及设置开关的持久化。

运行新版前退出旧版 Sonora，配置目录继续沿用。
