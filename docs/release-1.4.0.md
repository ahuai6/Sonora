# Sonora 1.4.0

修复 1.3.3 审计确认的 10 项缺陷，落实音乐整理、恢复、队列、歌词和音源策略建议。下载仍只生成音频文件，标签、封面和可取得的双语歌词写入音频内部。

## 实际音质与 API

播放面板、底部播放器、下载中心和本地音乐显示编码、位深、采样率、声道及可取得的码率。请求档位单独显示；API 声明标记为“接口报告”，未检测时显示“待音频确认”。下载解析完整文件，播放探测最多 256 KiB、6 秒超时；大封面 FLAC 可直接读取 STREAMINFO。有损编码没有位深时不会虚构位深。全景声、环绕声、音效并不保证更高保真度。

| 平台    | 新增 / 修正的原生档位                                                                                                    |
| ------- | ------------------------------------------------------------------------------------------------------------------------ |
| 网易云  | 下载使用支持 level 的原生 URL 路径；Hi-Res `hires`、母带 `jymaster`、全景声 `vivid`、沉浸环绕 `sky`、高清臻音 `jyeffect` |
| QQ 音乐 | 独立 vkey 适配：Hi-Res `RS01`、母带 `AI00`、全景声 `Q000`、环绕声 `Q001`；不再把 Hi-Res 交给仅识别 FLAC 的 SDK 参数      |
| 酷狗    | `high`、母带 `viper_tape`、全景声 `viper_atmos`、超清 `viper_clear`、DSD `super`                                         |

平台仍决定歌曲发行规格、会员、地区和设备权限。DSF / DFF 可识别、下载及导入，Electron 可能无法播放 DSD；标签不受支持时保留音频并报告未写入。加密或无法识别的响应不会伪装成 FLAC，不进行升级转码。自建接口的实际能力仍由用户配置的上游决定。

2026-10-31 隔离匿名探测中，网易云曲目 33894312 请求 Hi-Res 和母带均返回 **MP3、44.1 kHz、2 声道、320 kbps**，新版按此实测显示。QQ / 酷狗母带未取得地址，未据此判定接口已失效，也未声称通过会员音源实测。

本次核对的上游协议实现：

- [网易云 song_url_v1](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/main/module/song_url_v1.js)
- [QQ SDK getMusicPlay](https://github.com/sansenjian/qq-music-api/blob/main/src/services/apis/music/getMusicPlay.ts) 与 [扩展档位映射](https://github.com/AynaLivePlayer/miaosic/blob/main/providers/qq/quality.go)
- [酷狗 song_url](https://github.com/MakcRe/KuGouMusicApi/blob/main/module/song_url.js)

运行 `node scripts/check-quality-live.mjs` 可进行无账号的有限探测，结果写入被 Git 忽略的 outputs 目录。网络及平台状态可能变化。

## 功能入口与行为

- **本地音乐 → 批量标签与整理工具**：匹配并预览每个字段的新旧值，勾选后写入；封面、歌词分别可选。不会直接用模糊候选覆盖整批歌曲。恢复中心支持查看、恢复和清理历史音频备份。
- 扫描目录与下载目录监听变化，防抖后增量核对。手动移除的记录不会被自动扫描重新加入；主动扫描或导入仍可重新加入。
- 缺失文件从主列表移出，但保留身份、收藏和添加时间，可重新定位。不能用已关联的其他文件悄悄覆盖原记录。
- **偏好与音源 → 平台独立音质与音源**：分别选择音质、音源和自动取链顺序。诊断预览显示最近接口及备用源健康结果，并提供账号、接口、下载的处理入口。
- 搜索可选择合并同曲候选，按完整曲名、歌手、专辑和接近时长匹配。保留现场、翻唱、重制等版本文本，所有平台候选仍可展开选择。
- 队列支持拖动、上移 / 下移、移除、清空和保存。记忆播放位置、音量、循环模式；重启恢复为暂停，点击播放继续。
- 标签歌词页提供时间轴预览、逐字高亮、翻译、倒序 / 文本一致性校验及导出；可手动编辑 LRC / 增强 LRC / TTML 的文本与时间戳。
- 列表交换支持 M3U8、CSV、JSON：本地音乐、下载文件、队列和当前已加载的歌单。导入在线引用后可从整理工具播放，本地路径则加入音乐库。M3U8 的平台引用使用 Sonora 协议，其他播放器不一定支持。
- 下载中心可只重试内嵌信息，保留音频。提交阶段有 SHA-256 意向记录，重启核对已保存文件；失败任务已有可用文件时重建记录，不重复下载。
- 大列表每页渲染 100 行；TagLib 写入移至工作线程。关闭窗口等待进行中的文件修改和下载提交结束。

## 审计逐项修复

| 编号 | 修复                                                                    |
| ---- | ----------------------------------------------------------------------- |
| A01  | 损坏状态先保留副本、尝试 last-good 恢复，校正无效数组和新增状态字段形状 |
| A02  | 切歌前清除旧音频，失败时重新解析，加载时禁用播放快捷键                  |
| A03  | 保留增强 LRC 首个逐字时间前的原文，显示和导出一致                       |
| A04  | 普通歌单 / 榜单成功后推进页码，失败重试同一页                           |
| A05  | 备用取链读取公开账号摘要，不触发凭据解密                                |
| A06  | 按官方页面 URL 获取 Cookie，保留有效父域 Cookie                         |
| A07  | 账号验证采用可取消 SDK 工作线程和总超时                                 |
| A08  | 最终文件创建成功后，临时文件清理失败不再把下载记为失败                  |
| A09  | 非音频不计为成功导入，异常元数据提供错误信息                            |
| A10  | 异步解析后读取当前音量，避免旧闭包覆盖                                  |
| R01  | minimatch 锁定 11.0.1，适配两处旧构建导入，验证干净安装及真实打包       |
| R02  | 主检查和发布流程加入批量管理及本版专项桌面回归                          |

minimatch 的兼容处理仅调整 ASAR、dir-compare 的导入方式，使用上游公开函数，没有替换匹配算法或隐藏审计。参见 [安全公告](https://github.com/advisories/GHSA-g3hv-75wg-m249)。

同步更新 Electron 至 45.2.1、music-metadata 至 12.3.3、lucide-react 至 1.66.0。Node 类型保持与 Electron 的 Node 24 对齐；QQ SDK 与 electron-builder 保留当前较高的已锁定版本，不因 latest 标签回退而降级。打包默认使用 7z 压缩级别 5，可通过 `ELECTRON_BUILDER_COMPRESSION_LEVEL` 覆盖，避免最大压缩造成过长构建等待。

## 验证范围

以项目支持的 npm 11.21.1 干净安装。验证包括核心回归、原桌面回归、批量管理、Jerry 升级、我的歌单、本版专项和发布成品检查。媒体为自有生成夹具，没有修改用户现有音乐或使用用户账号验证会员权益。

本地最终结果：134 项核心测试通过；打包成品的 85 项桌面检查通过（36 + 12 + 6 + 12 + 19），无渲染器错误；完整依赖审计 0 漏洞。便携 EXE 内可解出主程序和 app.asar，其 SHA-256 与通过回归的 win-unpacked 文件一致；项目主进程与配置文件逐一对比相同，未包含用户状态、测试目录或本机用户路径。

公开源及高规格文件受平台返回影响；匿名测试不代表所有地域、会员档位或全部歌曲均已验证。
