## 修正的实际接口差异

- QQ 的现代搜索接口会在匿名请求中返回过滤状态；应用保留旧查询协议与受限的关联资源回退，并将完整歌单搜索的失败原因显示给用户。
- QQ 的 media MID 与歌曲 MID 分开保留，避免构造错误音频文件名。
- 酷狗搜索返回 FileHash，专辑与榜单返回 audio_info 下的 hash / hash_128；已统一处理。
- 酷狗榜单同时返回分类 id 和真实 rankid，应用使用后者（例如 TOP500 的 rankid 为 8888），避免打开过时分类数据。
- 账号凭据只存于本机加密数据；公共备用取链服务不继承平台账号 Cookie。

## 保留的边界

本次未借用或读取用户既有账号、浏览器 Cookie 或音乐库。完整账号流程需使用者亲自登录；外部接口随时可能变更。应用为未签名免安装版，未配置自动更新或自动删除音乐的计划任务。暂停后重试会从头下载。
