# Sonora 1.6.0

- 「本地音乐 → 编辑音乐标签 → 内嵌歌词 → 翻译与匹配内嵌歌词」可读取并选择 MP3、FLAC、M4A 中的 LRC 或 TTML 字段。
- 粘贴纯译文、双语文本或带时间戳的 LRC 后，可按时间戳、原句和顺序匹配，手动调整对应行并应用到译文草稿。网易云、QQ 音乐、酷狗和 LRCLIB 的搜索结果支持预览并加入匹配。
- AI 翻译支持 OpenAI 及兼容的 Responses / Chat Completions 服务。在窗口输入 API 地址、模型与所需 Key，Key 只保留在本次窗口会话。提交翻译请求时发送歌曲信息和逐行原词。
- 确认后将译文写回原歌词字段，也可单独删除该字段。保存前校验音频及其他标签，保留原文件备份。支持可验证的 ID3v2、FLAC Vorbis 注释和非分片 M4A 容器，单文件上限 512 MB。
- 标签匹配结果新增歌词预览与复制。标签编辑器关闭时以独立弹窗确认是否放弃草稿。
