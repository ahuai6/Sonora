# Sonora 1.3.2

JerryMusicAPI 已作为网易云备用音源随 Windows 发布包提供，包含接口地址、歌曲 ID / 音质参数映射、响应校验、30 秒超时以及旧配置兼容逻辑。

## 使用

打开“偏好与音源 → 备用取链服务 → 使用的音源”，选择“JerryMusicAPI · 网易云”。此选项直接使用 Jerry 获取网易云音频地址，不需要另外导入接口 JSON。

自动模式仍按既有顺序取链，默认优先内置平台接口；也可保持“仅内置平台接口”。选中 Jerry 后，取链请求不发送平台账号 Cookie。Jerry 当前接入仅支持网易云，其他平台选择它会提示不支持。

包内提供的是 Sonora 的客户端接入配置与调用逻辑，运行时联网访问 Jerry 公共服务，不包含上游服务端部署。公共服务在不同网络下的可用性仍以实际返回为准。

## 升级兼容

- 旧 `providers.json` 缺少 Jerry 时，从包内默认配置补入，首次启动不覆盖原文件；保存接口设置时再持久化。
- 已有 Jerry 地址、超时、参数及禁用状态保留；已经完成本次兼容后再明确删除入口，也不会反复补入。
- 旧配置损坏时，从最近有效配置恢复，并为缺少入口的旧备份补入 Jerry；损坏原文件保留。
- 导入旧 JSON 后，设置页显示实际生效配置，无需重启。

## 针对性验证

- 7 项核心测试通过，覆盖响应映射、歌曲 ID / 状态检查、试听识别、Cookie 隔离、旧配置补入、自定义值保留、持久化与损坏配置恢复。
- 另有 2 项相关回归通过，覆盖损坏配置恢复与手动音源不静默切换。
- 6 项桌面检查通过，验证旧配置下入口可见且可选、手动选择和接口保存、重启后保留选择、无渲染异常。
- Windows 打包版运行相同桌面检查；打包命令直接检查 `app.asar`，确认 Jerry 默认入口和兼容模块确实随包分发。

本地仅运行 Jerry 相关检查与构建，使用隔离配置及本地响应夹具，不把开发环境网络失败作为公共服务失效证据。GitHub 发布工作流按标签触发，不持续追踪云端构建。
